# seed-and-scale

**The Water Bill** — a water-stress exposure analysis for the global rice trade, built by team
Seed & Scale for the 2026 Women in Data "What's Cooking?" Datathon.

For a rice-importing country, how exposed is its supply to water stress in the countries it buys
from, and what happens to that supply if a stressed supplier's exports drop? This project scores
that exposure, simulates supply shocks, and — using each supplier's *measured* spare capacity
rather than an assumed unlimited one — ranks who could realistically scale up to cover the gap.
